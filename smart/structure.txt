# Smart Monitoring: Project Structure & Data Traceability

## 1. Architecture in One Minute

The `features/` folder follows an **MVVM pattern**. Every feature is split the same way:

| Layer | Folder | Responsibility |
|---|---|---|
| **Model** | `models/` | Shape/normalisation of data (what a Production, Product, User looks like) |
| **Service** | `services/` | API calls only. No UI, no state |
| **View-Model** | `view-models/` | React hooks (`use-...-view-model.js`) holding logic, state, grouping and calculations for a screen |
| **View** | `views/` | Pure UI (`.jsx`) that renders what the view-model gives it |
| **Store** | `store/` | Global client state (auth only) |

Pages in `src/app/` stay thin: they pick a view-model and render a view or cards.
