SRC/FEATURES - FEATURE-BASED MODULES
--------------------------------------------------------------------------------

Each feature follows the pattern: models/, services/, view-models/, views/,
and optionally store/.

--- auth: Authentication ---

src/features/auth/models/auth.model.js
  normalizeLoginResponse(): Extracts token and user from API login response.
  Handles multiple possible field names (token, access_token, accessToken,
  user, employee).

src/features/auth/models/login.schema.js
  Zod validation schema for the login form. Validates employee_id and password
  as required strings.

src/features/auth/services/auth.service.js
  authService.login(credentials): Calls the login API endpoint and normalizes
  the response using normalizeLoginResponse.

src/features/auth/store/auth.store.js
  Zustand store for authentication state. Manages user, token,
  isAuthenticated, and hasHydrated. Persists to localStorage (key: "xoomgrid-auth").
  Provides setAuth(), setUser(), logout(), setHasHydrated() actions.

src/features/auth/view-models/use-login-view-model.js
  Login view logic. Handles form state (react-hook-form + zod), submission,
  mutation via TanStack Query, token storage in localStorage, and redirection
  to dashboard on success.

src/features/auth/view-models/use-auth-role.js
  Hook that decodes the user's role from the stored user object or JWT token.
  Returns { role, isSuperAdmin }.

src/features/auth/views/login-view.jsx
  Login page UI. Beautiful gradient background with form, password toggle,
  remember me, server error display, and submit button.

ARCHITECTURE OVERVIEW
--------------------------------------------------------------------------------

Pattern: Feature-based organization with separation of concerns:

  views/      -> UI components (React components, JSX)
  view-models -> Business logic (hooks, form handling, data fetching)
  services    -> API layer (Axios calls, endpoint construction)
  models      -> Data normalization/validation (Zod schemas, response mappers)
  store       -> Global state (Zustand stores, only in auth)

State Management:
  - Zustand: Authentication state (useAuthStore)
  - TanStack Query: Server state caching (QueryProvider)
  - React Hook Form + Zod: Form validation

Styling: Tailwind CSS v4 with shadcn/ui component patterns
Icons: Lucide React
Date formatting: date-fns with Asia/Kolkata timezone
Charts: Recharts
